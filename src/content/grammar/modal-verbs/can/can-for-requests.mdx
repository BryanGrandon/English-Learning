We use **can** to make simple and informal requests.

A request is when we ask someone to do something for us or to give us something.

---

## Making a Request

The basic structure is:

> **Can + subject + base verb?**

When asking someone to do something, the subject is usually **you**.

- **Can you help** me?
- **Can you open** the door?
- **Can you repeat** that?
- **Can you speak** more slowly?
- **Can you wait** a minute?

---

## Asking for Something

We can also use **Can I have...?** to ask for something.

- **Can I have** some water?
- **Can I have** a coffee?
- **Can I have** the menu?
- **Can I have** a ticket, please?

We can add **please** to make the request more polite.

- Can you help me, **please**?
- Can I have some water, **please**?

---

## Responding to Requests

When someone makes a request, we can accept or refuse.

### Accepting

- Sure.
- Of course.
- Yes, no problem.
- Sure, I can.

### Refusing

- Sorry, I can't.
- I'm sorry, I can't.
- Sorry, not right now.

---

## Can for Requests vs. Permission

The same structure can have different purposes.

### Request

> **Can you open the window?**

You are asking another person to open the window.

### Permission

> **Can I open the window?**

You are asking if you are allowed to open the window.

Compare:

| Sentence               | Function   |
| ---------------------- | ---------- |
| Can you help me?       | Request    |
| Can I use your phone?  | Permission |
| Can you open the door? | Request    |
| Can I sit here?        | Permission |

---

## Please

**Please** is commonly used with requests.

- Can you help me, **please**?
- Can you repeat that, **please**?
- Can I have some water, **please**?

It makes the request sound more polite.

---

## Common Mistakes

- ❌ Can you **to help** me?
- ✅ Can you **help** me?
- ❌ Can you **helps** me?
- ✅ Can you **help** me?
- ❌ Can I **to have** some water?
- ✅ Can I **have** some water?

---

## Quick Summary

- Use **Can you...?** to make a simple request.
- Use **Can I have...?** to ask for something.
- Add **please** to make requests more polite.
- Use the **base form** after _can_.
- **Can you...?** usually asks someone to do something.
- **Can I...?** can ask for permission.
