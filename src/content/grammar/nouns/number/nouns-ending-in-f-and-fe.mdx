Some nouns ending in -f or -fe change their ending to -ves when they become plural.

However, this is not a rule for every noun ending in -f or -fe.

---

## F -> VES

Some nouns change -f to -ves.

- leaf -> leaves
- wolf -> wolves
- shelf -> shelves
- half -> halves
- life -> lives

The leaves are falling from the trees.

---

## FE -> VES

Some nouns ending in -fe change -fe to -ves.

- wife -> wives
- knife -> knives
- life -> lives

The chef has three knives.

## Not All Nouns Follow This Rule

Some nouns ending in -f simply take -s.

- roof -> roofs
- belief -> beliefs
- chef -> chefs
- cliff -> cliffs

Some nouns ending in -fe can also simply take -s.

- safe -> safes

The building has several roofs.

## Compare the Forms

| Singular | Plural  |
| -------- | ------- |
| leaf     | leaves  |
| wolf     | wolves  |
| shelf    | shelves |
| knife    | knives  |
| wife     | wives   |
| roof     | roofs   |
| chef     | chefs   |
| belief   | beliefs |

## Why Is This Important?

The -f -> -ves pattern is common, but it is not completely predictable.

For this reason, it is useful to learn these plural forms as vocabulary.

- leaf -> leaves
- knife -> knives
- roof -> roofs

---

## Common Mistakes

- ❌ leafs
- ✅ leaves
- ❌ knifes
- ✅ knives
- ❌ wifes
- ✅ wives

### But:

- ❌ rooves
- ✅ roofs

---

## Quick Summary

Some nouns ending in -f or -fe change to -ves:

- leaf -> leaves
- wolf -> wolves
- knife -> knives
- wife -> wives

Others simply add -s:

- roof -> roofs
- chef -> chefs
- belief -> beliefs

There is no universal rule, so common exceptions should be learned individually.
