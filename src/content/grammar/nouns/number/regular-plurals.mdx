Regular plural nouns follow predictable spelling rules. Most plural nouns are formed by adding -s or -es to the singular form.

| Ending                                 | Plural Rule                   | Example          |
| -------------------------------------- | ----------------------------- | ---------------- |
| most nouns                             | add **-s**                    | book -> books    |
| **-s, -ss, -sh, -ch, -x, -z**          | add **-es**                   | bus -> buses     |
| consonant + **y**                      | change **-y** to **-ies**     | party -> parties |
| vowel + **y**                          | add **-s**                    | boy -> boys      |
| some nouns ending in **-f** or **-fe** | change **-f/-fe** to **-ves** | leaf -> leaves   |

---

## Add -s

For most nouns, add -s to form the plural.

| Singular | Plural   |
| -------- | -------- |
| book     | books    |
| car      | cars     |
| dog      | dogs     |
| table    | tables   |
| student  | students |

- #### Examples
  - I have one book.
  - I have two books.
  - She has a dog.
  - They have three dogs.

---

## Add -es

Add -es to nouns ending in -s, -ss, -sh, -ch, -x, or -z.

| Singular | Plural  |
| -------- | ------- |
| bus      | buses   |
| class    | classes |
| dish     | dishes  |
| watch    | watches |
| box      | boxes   |
| quiz     | quizzes |

- #### Example
  - There are two buses outside.
  - We have three classes today.
  - She washes the dishes.
  - I have two watches.

---

## Consonant + Y

When a noun ends in a consonant + y, change y to i and add -es.

**_y → ies_**

| Singular | Plural    |
| -------- | --------- |
| baby     | babies    |
| city     | cities    |
| country  | countries |
| family   | families  |
| party    | parties   |

- #### Example
  - The baby is sleeping.
  - The babies are sleeping.
  - There are many cities in this country.
  - We have two parties this month.

---

## Vowel + Y

When a noun ends in a vowel + y, simply add -s.

**_y → ys_**

| Singular | Plural |
| -------- | ------ |
| boy      | boys   |
| day      | days   |
| key      | keys   |
| toy      | toys   |
| way      | ways   |

- #### Example
  - There is one boy in the room.
  - There are three boys in the room.
  - I have two keys.
  - We work five days a week.

### Compare

| Consonant + Y     | Vowel + Y  |
| ----------------- | ---------- |
| baby → babies     | boy → boys |
| city → cities     | day → days |
| family → families | key → keys |
| party → parties   | toy → toys |

---

## Some Nouns Ending in -f or -fe

Some nouns ending in -f or -fe change to -ves in the plural.

| Singular | Plural |
| -------- | ------ |
| knife    | knives |
| wife     | wives  |
| leaf     | leaves |
| life     | lives  |

However, some nouns ending in -f simply take -s.

| Singular | Plural  |
| -------- | ------- |
| roof     | roofs   |
| chef     | chefs   |
| belief   | beliefs |

These forms need to be learned individually.

## Quick Reference

| Ending                    | Plural Rule   | Example        |
| ------------------------- | ------------- | -------------- |
| Most nouns                | + -s          | book → books   |
| -s, -ss, -sh, -ch, -x, -z | + -es         | box → boxes    |
| Consonant + y             | y → ies       | city → cities  |
| Vowel + y                 | + -s          | boy → boys     |
| Some -f/-fe               | -f/-fe → -ves | knife → knives |

## Common Mistakes

- ❌ two box
- ✅ two boxes
- ❌ two citys
- ✅ two cities
- ❌ two boies
- ✅ two boys
- ❌ two rooves
- ✅ two roofs
