## What Does "There Is" Mean?

**There is** is used to say that something exists or is located somewhere.

It is normally used with **one person, one thing, or an uncountable noun**.

### Structure

**_There is + singular noun_**

Examples:

- There is a book on the table.
- There is a student in the classroom.
- There is a problem.
- There is some water in the bottle.

The contraction **there's** is very common in everyday English.

**_There is → There's_**

Examples:

- There's a book on the table.
- There's a problem.
- There's some milk in the fridge.

---

## There Is with Singular Nouns

Use **there is** with singular countable nouns.

### Structure

**_There is + a/an + singular noun_**

Examples:

- There is a cat in the garden.
- There is a computer on the desk.
- There is an apple in the bag.
- There is an English book on the table.

Remember to use **a** before a consonant sound and **an** before a vowel sound.

---

## There Is with Uncountable Nouns

**There is** can also be used with uncountable nouns.

Examples:

- There is some water in the glass.
- There is milk in the fridge.
- There is rice on the plate.
- There is information on the website.

Uncountable nouns do not normally use **a/an**.

- There is water.
  - ~~There is a water.~~

---

## Negative Form

To make a negative sentence, use **not** after **is**.

### Structure

- _There is not + noun_

The common contraction is:

- _There isn't + noun_

Examples:

- There isn't a chair in the room.
- There isn't a supermarket nearby.
- There isn't any milk in the fridge.
- There isn't a problem.

### Full and Contracted Forms

| Full form    | Contracted form |
| ------------ | --------------- |
| There is not | There isn't     |

---

## Questions

To make a question, put **is** before **there**.

### Structure

> **Is there + noun?**

Examples:

- Is there a bank near here?
- Is there a bathroom upstairs?
- Is there a problem?
- Is there any water?

### Short Answers

| Question            | Positive       | Negative         |
| ------------------- | -------------- | ---------------- |
| Is there a bank?    | Yes, there is. | No, there isn't. |
| Is there a problem? | Yes, there is. | No, there isn't. |
| Is there any milk?  | Yes, there is. | No, there isn't. |

Do not use **Yes, there's** or **No, there isn't** as the standard short-answer pattern.

- **Is there a problem?**
  - Yes, there is.

---

## There Is with Place

**There is** is often followed by a place expression.

### Structure

- **There is + noun + place**

Examples:

- There is a book **on the table**.
- There is a park **near my house**.
- There is a restaurant **next to the hotel**.
- There is a computer **in the classroom**.

The place expression tells us **where** something exists.

---

## Common Mistakes

### Using "there are" with a singular noun

- ❌ There are a book on the table.
- ✅ There is a book on the table.

### Using "there is" with a plural noun

- ❌ There is two chairs in the room.
- ✅ There are two chairs in the room.

### Using "a/an" with an uncountable noun

- ❌ There is a water in the glass.
- ✅ There is some water in the glass.

---

## Quick Summary

- **There is** is used with singular nouns and uncountable nouns.
- **There's** is the common contraction of **there is**.
- Negative: **There isn't**.
- Question: **Is there...?**
- Short answer: **Yes, there is. / No, there isn't.**
- Use a place expression when you want to say where something is.

### Basic Pattern

- **There is + singular/uncountable noun + place**

**Example:** There is a book on the table.
